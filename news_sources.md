# Источники новостей CORTEX

Файл конфигурации доверенных новостных каналов и RSS-лент для агрегатора и LLM-редактора (`scripts/news_engine.py`).

> **Примечание по архитектуре:**  
> Этот файл является единым источником правды (Single Source of Truth). В самом веб-приложении CORTEX читатели могут только включать и отключать эти источники чекбоксами под свои предпочтения. Новые каналы подключаются автором здесь через коммит в репозиторий.

## Правила добавления источников для автора

1. **Telegram-каналы:**
   - В поле «Тип» укажите `telegram`.
   - В поле «Адрес / Канал» укажите username канала (например, `durov` или `mash`). Канал должен быть публичным.
2. **RSS-ленты:**
   - В поле «Тип» укажите `rss`.
   - В поле «Адрес / Канал» укажите прямую ссылку на XML/RSS ленту.
3. **Рубрики:**
   - `main` — Главное
   - `russia` — Россия
   - `city` — Город
   - `world` — Мир
   - `tech` — Технологии
   - `telegram` — Telegram
