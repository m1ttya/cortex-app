Прямая запись без окон сохранения

В браузере Brave прямая тихая перезапись файлов на диске по умолчанию отключена разработчиками браузера из соображений приватности.

Чтобы кнопка «Сохранить» писала в файл в 1 клик без всплывающих окон:

Способ 1 (Самый простой — без настроек):
Откройте эту страницу в Microsoft Edge или Chrome — там прямая запись на диск работает сразу «из коробки».
Способ 2 (Включить прямую запись в Brave):
1. Откройте в новой вкладке адрес:
brave://flags/#file-system-access-api
2. Переключите в Enabled и нажмите Relaunch.

Не подключено
Синхронизируйте базу cortex_db.json с вашим личным репозиторием на GitHub. Изменения сохраняются автоматически.
Инструкция: как создать токен за 1 минуту (бесплатно)
  1. Создайте репозиторий на GitHub (можно Private), например cortex-data.
  2. Перейдите в GitHub ➔ Settings ➔ Personal Access Tokens.
  3. Нажмите Generate new token, выберите репозиторий cortex-data.
  4. В блоке Repository permissions выберите Contents: Read and write.
  5. Скопируйте полученный токен и вставьте в поле выше.
🔒 Токен сохраняется только в браузере (LocalStorage) и отправляется исключительно на официальный api.github.com по HTTPS.
Файл на диске не выбран
Выберите файл cortex_db.json или создайте новый. Все изменения автоматически записываются на диск.
💡 100% автономно: Работа с физическим файлом на диске через стандартный File System Access API (Chrome, Edge). Добавление, редактирование и удаление материалов сохраняются сразу в файл без всплывающих окон.
