# 🧠 CORTEX – Персональная база знаний и умные новости

Удобное и быстрое веб-приложение для сохранения полезных ссылок, организации заметок, трекинга обучения и чтения новостей без информационного шума.

---

## ✨ Возможности

### 🗂️ Второй мозг
* **Быстрое добавление:** сохраняйте статьи, видео, книги, лекции и задачи в один клик.
* **Папки и структура:** раскладывайте материалы по папкам с удобной навигацией.
* **Перетаскивание (Drag-and-Drop):** легко перемещайте карточки между папками и статусами.
* **Два режима просмотра:**
  * **Список** – таблица с прогрессом изучения, оценками и личными заметками.
  * **Канбан-доска** – наглядные колонки «В планах», «В процессе» и «Готово».
* **Поиск и фильтры:** мгновенный поиск по названиям, тегам и форматам материалов.

### ⚡ Умная лента новостей
* **Главное без воды:** подборка важных событий из проверенных источников.
* **Сжатая суть:** новости сгруппированы по темам, а самое главное выделено в 2–3 ключевых тезиса.
* **Сохранение в один клик:** понравившуюся новость можно сразу отправить в личную базу знаний.

### 💾 Полный контроль над данными
* **Автосохранение:** любое изменение сразу сохраняется в реальном времени.
* **Выбор места хранения в один клик:**
  * **Через GitHub** – автоматическая синхронизация между всеми вашими устройствами через личный репозиторий.
  * **Локальный диск** – сохранение напрямую в файл на вашем компьютере для автономной работы.
* **Резервные копии:** выгрузка базы в файл JSON и загрузка обратно в любой момент.

---

## 🚀 Как начать пользоваться

1. Откройте приложение в браузере.
2. В верхнем блоке нажмите кнопку **«База данных»**.
3. Выберите удобный для вас вариант:
   * **Через GitHub** – укажите ваш репозиторий и токен для синхронизации.
   * **Локальный диск** – выберите или создайте файл на компьютере.
4. Добавляйте первые материалы и наводите порядок в знаниях!
