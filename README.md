# 🧠 CORTEX — Second Brain & AI News Digest

Современное веб-приложение (PWA) для организации базы знаний, трекинга обучения и умной новостной ленты с суммаризацией через нейросети (LLM).

![CORTEX Preview](https://raw.githubusercontent.com/m1ttya/cortex-app/main/manifest.json)

---

## ✨ Основные возможности

### 1. 🗂️ Второй мозг (База знаний и трекинг)
* **Быстрый захват (Quick Capture):** Добавление ссылок, заметок и материалов в 1 клик с выбором типа (`Читать`, `Смотреть`, `Изучать`, `Сделать`), приоритета и стартового статуса.
* **Файловая система Проводника Windows:** Организация материалов по вложенным папкам любого уровня.
* **Нативный Drag-and-Drop:** Перетаскивание материалов в папки и возврат на уровень выше через кнопку `[ ⮤ Вверх ]` и строку хлебных крошек пути.
* **Два режима отображения:**
  * **Интерактивный список:** Таблица со статусами, процентами прогресса, оценками и заметками.
  * **Канбан-доска:** Столбцы «В планах», «В процессе», «Готово» с поддержкой перетаскивания.
* **Виртуальный скроллинг (Virtual Scroll):** Молниеносная скорость работы и 60 FPS даже при 10 000+ записей.

### 2. ⚡ Умная лента новостей (AI Digest)
* **Агрегация СМИ и Telegram:** Сбор новостей из ведущих источников (РБК, Коммерсантъ, ТАСС, Хабр, 3DNews) и открытых Telegram-каналов без API ключей мессенджера.
* **LLM-обработка без воды:** Нейросеть группирует повторяющиеся инфоповоды, удаляет кликбейт и оставляет 2–3 ключевых тезиса с первоисточниками.
* **В базу в 1 клик:** Любую новость из ленты можно мгновенно сохранить в личный Второй мозг кнопкой `+ В базу знаний`.
* **Автоматизация через GitHub Actions:** Робот собирает свежий дайджест каждые 2 часа в фоне.

### 3. 🔒 Приватность и безопасность (BYOS — Bring Your Own Storage)
* **100% Client-Side:** Приложение работает полностью в браузере.
* **Изоляция данных:** Личные материалы хранятся либо в вашем закрытом репозитории GitHub (`Private Repo`), либо в локальном JSON-файле на диске.
* **Никаких утечек API ключей:** Ключи от LLM хранятся либо в защищённых GitHub Secrets, либо в локальном браузере (`localStorage`).

## 🚀 Запуск и развёртывание

### Быстрый запуск локально
Так как проект написан на чистом стеке (HTML, Vanilla CSS, JS), достаточно любого статического сервера:
```bash
# Python
python -m http.server 8080

# или npx serve
npx serve .
```
Откройте в браузере: `http://localhost:8080`.

### Развёртывание на GitHub Pages
1. В настройках репозитория перейдите в **Settings** → **Pages**.
2. В **Build and deployment** выберите ветку `main` и папку `/ (root)`.
3. Нажмите **Save** — сайт готов к использованию по адресу `https://<username>.github.io/<repo>/`.
